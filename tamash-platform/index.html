Your project, your workflow

Alongside development.
Or in a dedicated QA repository.

Use the repository setup that fits your team and application.

01

Alongside application development

Keep application code, quality definitions, and automation in the same repository. Validate during development and run tests again in CI.

02

In a dedicated QA repository

Keep quality assets in a separate repository and validate the deployed application. Work with third-party, packaged, or legacy systems without application source code.

In either setup, quality assets participate in Git history and review. Your existing runners and CI remain part of the workflow.
