Get started

From install to a healed run
in ten minutes.

Your trial gives you two things from the TAMASH portal: an npm token to install the packages and a key for your project. Nothing else changes in how you run Playwright or Cucumber.

01

Install

Add Shield and RunSights to your Playwright project.

npm install --save-dev @vibetestq/tamash-shield @vibetestq/tamash-runsights
npx tamash-shield init

init adds the RunSights reporter to your Playwright config and a place for the project key in .env.

02

Add the key and sign in

Copy the project key from Projects in the portal into .env, then sign this machine in from the browser.

TAMASH_LICENSE_KEY=<your project key>
npx tamash-shield login

The portal opens, you approve the machine by name, and it gets its own access token. CI pipelines use a service token instead.

03

Run as usual

Run your tests the way you always do.

npx playwright test

Healed locators show in the console as they happen. The run, its failures and its healing activity are in RunSights when it ends. npx tamash-shield doctor checks the setup.
