Auto-Waiting: What It Means in Practice

Before Every Action, Playwright:

  • Waits for element to exist in DOM
  • Waits for element to be visible
  • Waits for element to be stable (stop animating)
  • Waits for element to be enabled
  • Waits for element to receive focus
  • Scrolls element into view

What You Should NOT Do

  • page.waitForTimeout(3000)
  • sleep() in test code
  • Manual wait after every click
  • Polling with setInterval
  • Retrying with try/catch loops

Trust the auto-wait. Only add explicit waits when you need to wait for network events, custom conditions, or non-element state changes.

Click and Mouse Actions

// Standard click — auto-waits for actionable state await page.getByRole('button', { name: 'Submit' }).click(); // Click options await element.click({ button: 'right' }); // right-click await element.click({ clickCount: 2 }); // double-click await element.click({ modifiers: ['Shift'] }); // shift+click await element.click({ position: { x: 10, y: 5 } }); // at coordinates // Convenience methods await element.dblclick(); await element.hover(); // triggers CSS :hover, opens dropdowns await element.focus(); // sets focus without clicking // Tap for mobile contexts await element.tap(); // Check / Uncheck await page.getByRole('checkbox', { name: 'Agree' }).check(); await page.getByRole('checkbox', { name: 'Agree' }).uncheck(); await page.getByRole('checkbox').setChecked(true); // Force click — bypasses actionability (use sparingly!) await element.click({ force: true });

Form Input Actions

// fill() — clears existing value then types (recommended for inputs) await page.getByLabel('Email').fill('user@example.com'); // pressSequentially() — types char by char, triggers keystroke events await page.getByLabel('Search').pressSequentially('playwright', { delay: 50 }); // clear() — empty an input field await page.getByLabel('Email').clear(); // selectOption() — dropdowns await page.getByRole('combobox').selectOption('chrome'); await page.getByRole('combobox').selectOption({ label: 'Google Chrome' }); await page.getByRole('listbox').selectOption(['option1', 'option2']); // multi-select // File upload await page.getByLabel('Upload file').setInputFiles('path/to/file.pdf'); await page.getByLabel('Upload').setInputFiles(['file1.png', 'file2.png']); await page.getByLabel('Upload').setInputFiles([]); // remove // File upload via dialog intercept page.on('filechooser', async (chooser) => { await chooser.setFiles('tests/fixtures/sample.pdf'); }); await page.getByRole('button', { name: 'Upload' }).click();

Keyboard and Special Keys

// press() on a specific element await page.getByLabel('Search').press('Enter'); await page.getByTestId('input').press('Tab'); // Keyboard shortcuts — page-level await page.keyboard.press('Control+A'); // select all await page.keyboard.press('Control+C'); // copy await page.keyboard.press('Control+V'); // paste await page.keyboard.press('Escape'); await page.keyboard.press('ArrowDown'); await page.keyboard.press('F12'); // Click while holding key await element.click({ modifiers: ['Meta'] }); // Cmd+Click await element.click({ modifiers: ['Control'] }); // Ctrl+Click // Type into focused element await page.keyboard.type('Hello World'); await page.keyboard.down('Shift'); await page.keyboard.press('ArrowLeft'); await page.keyboard.up('Shift');

Common Key Names

  • Enter, Tab, Escape, Space
  • ArrowUp, ArrowDown, ArrowLeft, ArrowRight
  • Home, End, PageUp, PageDown
  • Backspace, Delete
  • Control, Meta, Alt, Shift
  • F1–F12, Insert

Drag & Drop and Scroll

// Drag and drop — two approaches // 1. dragTo() — recommended for accessible DnD await page.getByTestId('task-item').dragTo(page.getByTestId('done-column')); // 2. mouse events — for complex custom DnD const source = page.getByTestId('card'); const target = page.getByTestId('dropzone'); await source.hover(); await page.mouse.down(); const box = await target.boundingBox(); await page.mouse.move(box.x + box.width/2, box.y + box.height/2); await page.mouse.up(); // Scroll await page.mouse.wheel(0, 500); // scroll down 500px await element.scrollIntoViewIfNeeded(); // ensure element visible await page.evaluate(() => window.scrollTo(0, 0)); // scroll to top // Scroll within a scrollable container await page.getByTestId('scroll-container').evaluate( el => el.scrollTop += 200 );

Always use dragTo() first. Only fall back to manual mouse events if the app uses a non-accessible custom DnD library.

Navigation and Page Actions

// Navigate — auto-waits for load await page.goto('https://example.com'); await page.goto('/dashboard', { waitUntil: 'networkidle' }); // Browser controls await page.goBack(); await page.goForward(); await page.reload(); // Wait for specific conditions await page.waitForURL('**/dashboard'); await page.waitForURL(/login/); await page.waitForLoadState('networkidle'); await page.waitForLoadState('domcontentloaded'); // Wait for element to appear (use sparingly — prefer assertions) await page.waitForSelector('[data-testid="modal"]'); // Screenshots await page.screenshot({ path: 'screenshot.png' }); await page.screenshot({ path: 'full.png', fullPage: true }); await element.screenshot({ path: 'element.png' });

Session 11 Recap

Core Actions

  • click(), dblclick(), hover() — mouse
  • fill() — clear + type (recommended)
  • pressSequentially() — char-by-char
  • check(), uncheck(), setChecked()
  • selectOption() — dropdowns
  • setInputFiles() — file upload

Best Practices

  • Never use page.waitForTimeout()
  • Trust auto-waiting — it handles timing
  • Use dragTo() for accessible DnD
  • keyboard.press() for shortcuts
  • waitForURL() after navigations
