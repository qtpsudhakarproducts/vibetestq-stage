Effective Prompt Engineering for Test Generation

The CLEAR Prompt Framework

  • Context — what app, what page, what stack
  • Limitations — what to avoid (no locators in tests)
  • Example — sample of existing code style
  • Action — exactly what to generate
  • Requirements — edge cases, patterns, constraints
PROMPT EXAMPLE: Context: Playwright + TypeScript, Page Object pattern. No locators in tests — only page methods. Action: Write a LoginPage class with: - getByLabel locators for Email, Password - login(email, password) method - verifyError(message) method using expect Requirements: Extend BasePage, TypeScript, all locators private

Prompts for Test Scenarios

PROMPT: Test case generation --- App: E-commerce checkout flow (React, REST API) Requirement: Users can apply discount codes at checkout Generate Playwright test scenarios for: 1. Valid discount code reduces total price 2. Expired discount code shows error message 3. Already-used discount code shows error 4. Invalid code format shows validation error 5. Discount applied correctly with multiple items in cart For each scenario, provide: - Test title - Preconditions - Steps (using page object methods) - Expected assertion Follow POM pattern — no locators or page.goto in tests. --- OUTPUT: Test file with test.describe block, beforeEach for login + navigation, and 5 test cases using page methods.

The more specific and structured your prompt, the less cleanup work you need. Use your code style as context.

  • /explain — explain selected code
  • /fix — fix a bug in selection
  • /tests — generate tests for function
  • /doc — add documentation
  • @workspace — ask about whole project

AI for Bug Analysis and Test Review

Bug Analysis Prompt

  • Paste error message + stack trace
  • Ask: "What caused this? How to fix?"
  • Ask: "What test would catch this?"
  • Ask: "Review my test for flakiness risks"
  • Ask: "Suggest better locators for this HTML"

Test Quality Review

  • Paste test file → ask for code review
  • "What scenarios am I missing?"
  • "Make this test more maintainable"
  • "Convert this to use Page Object pattern"
  • "Add boundary value test cases"

Use AI as a senior pair programmer. It reviews your tests, suggests improvements, and catches gaps in coverage — available 24/7.
