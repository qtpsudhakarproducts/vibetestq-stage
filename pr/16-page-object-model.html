POM: The Core Principle

Without POM (Anti-Pattern)

// test has locators + logic — FRAGILE test('add to cart', async ({ page }) => { await page.goto('/shop/widget-pro'); await page.locator('.product-qty').fill('3'); await page.locator('#add-cart-btn').click(); await expect(page.locator('.cart-count')).toHaveText('3'); }); // If div.product-qty changes → update ALL tests

With POM (Correct)

// test reads like plain English test('add to cart', async ({ productPage, cartBadge }) => { await productPage.openProduct('widget-pro'); await productPage.setQuantity(3); await productPage.addToCart(); await expect(cartBadge.count).toHaveText('3'); }); // Locator change → fix ONE page object method

Rule: Tests call page methods. Page objects own locators and actions. Never let a locator appear in a test file.

BasePage — Shared Foundation

// pages/BasePage.ts import { Page, Locator, expect } from '@playwright/test'; export abstract class BasePage { constructor(protected readonly page: Page) {} // Common navigation helpers async navigate(path: string): Promise<void> { await this.page.goto(path); } async waitForPageLoad(): Promise<void> { await this.page.waitForLoadState('networkidle'); } // Get page title for verification async getTitle(): Promise<string> { return this.page.title(); } // Scroll to an element async scrollTo(locator: Locator): Promise<void> { await locator.scrollIntoViewIfNeeded(); } // Wait for toast/notification async waitForSuccessToast(message: string): Promise<void> { await expect(this.page.getByRole('alert').filter({ hasText: message })) .toBeVisible({ timeout: 5000 }); } }

A Complete Page Object

// pages/LoginPage.ts import { Page, Locator, expect } from '@playwright/test'; import { BasePage } from './BasePage'; export class LoginPage extends BasePage { // All locators as readonly properties private readonly emailInput: Locator; private readonly passwordInput: Locator; private readonly submitButton: Locator; readonly errorMessage: Locator; constructor(page: Page) { super(page); this.emailInput = page.getByLabel('Email'); this.passwordInput = page.getByLabel('Password'); this.submitButton = page.getByRole('button', { name: 'Sign in' }); this.errorMessage = page.getByRole('alert'); } async navigate(): Promise<void> { await this.page.goto('/login'); await expect(this.submitButton).toBeVisible(); } async login(email: string, password: string): Promise<void> { await this.emailInput.fill(email); await this.passwordInput.fill(password); await this.submitButton.click(); } async verifyErrorShown(message: string): Promise<void> { await expect(this.errorMessage).toContainText(message); } }

Component Objects: Reusable UI Pieces

// components/NavBar.ts — reused across all page objects import { Page, Locator } from '@playwright/test'; export class NavBar { private readonly cartIcon: Locator; private readonly userMenu: Locator; private readonly searchBox: Locator; constructor(private page: Page) { this.cartIcon = page.getByTestId('nav-cart'); this.userMenu = page.getByTestId('nav-user-menu'); this.searchBox = page.getByRole('searchbox'); } async openCart() { await this.cartIcon.click(); } async openUserMenu() { await this.userMenu.click(); } async search(query: string) { await this.searchBox.fill(query); await this.searchBox.press('Enter'); } } // pages/ShopPage.ts — composing with components export class ShopPage extends BasePage { readonly nav = new NavBar(this.page); // composed component async searchForProduct(term: string): Promise<void> { await this.nav.search(term); } }

POM Folder Structure and Rules

pages/ BasePage.ts # abstract base LoginPage.ts DashboardPage.ts ProductPage.ts CartPage.ts CheckoutPage.ts AdminPage.ts components/ NavBar.ts # header navigation DataTable.ts # reusable table DatePicker.ts # reusable form widget Modal.ts # dialog/modal wrapper Toast.ts # notification component fixtures/ pages.fixtures.ts # injects pages into tests

POM Rules

  • No locators in test files — ever
  • Private locators, public methods
  • Methods do one thing clearly
  • Method names = user actions
  • Assertions can live in page objects
  • Extend BasePage for all pages

Session 16 Recap

Architecture

  • BasePage — shared navigation helpers
  • Page class per feature/page/module
  • Component classes for reusable UI
  • Fixtures inject page objects into tests
  • TypeScript gives IDE autocomplete + type safety

Design Rules

  • Private locators, public action methods
  • Tests read as plain English scenarios
  • One locator change = one fix location
  • Compose components inside page objects
  • Action methods verify their own success
