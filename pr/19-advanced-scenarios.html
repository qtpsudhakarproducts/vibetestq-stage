Working with iframes

// Get a frame by URL pattern or name const frame = page.frameLocator('iframe[src*="payment"]'); // Interact with elements inside the iframe await frame.getByLabel('Card Number').fill('4111111111111111'); await frame.getByLabel('Expiry').fill('12/26'); await frame.getByLabel('CVV').fill('123'); await frame.getByRole('button', { name: 'Pay Now' }).click(); // Frame by name attribute const namedFrame = page.frameLocator('iframe[name="paypal"]'); // Multiple nested iframes const outerFrame = page.frameLocator('#outer-frame'); const innerFrame = outerFrame.frameLocator('#inner-frame'); await innerFrame.getByRole('button', { name: 'Accept' }).click(); // Assert inside iframe await expect(frame.getByTestId('success-msg')).toBeVisible();

Use frameLocator() — it returns a FrameLocator, so you chain all normal locators on it. No special case handling needed.

Dialogs: alert, confirm, prompt

// MUST register dialog handler BEFORE triggering the action test('handles confirmation dialog', async ({ page }) => { await page.goto('/admin/users'); // Register handler before click page.on('dialog', async dialog => { expect(dialog.type()).toBe('confirm'); expect(dialog.message()).toContain('Are you sure?'); await dialog.accept(); // or dialog.dismiss() }); await page.getByRole('button', { name: 'Delete User' }).click(); await expect(page.getByText('User deleted')).toBeVisible(); }); // Handle prompt dialog and provide input value page.on('dialog', async dialog => { await dialog.accept('Jane Doe'); // input value for prompt }); // Dismiss alert page.on('dialog', async dialog => { await dialog.dismiss(); });

Multi-Tab and Popup Windows

// Wait for new tab to open when clicking a link test('link opens in new tab', async ({ context, page }) => { await page.goto('/'); // Wait for new page to be created const [newPage] = await Promise.all([ context.waitForEvent('page'), page.getByRole('link', { name: 'Documentation' }).click(), ]); await newPage.waitForLoadState(); await expect(newPage).toHaveURL(/docs/); await expect(newPage).toHaveTitle(/Documentation/); await newPage.close(); }); // Work across multiple tabs test('admin opens user in new tab', async ({ context, page }) => { await page.goto('/admin/users'); const [popup] = await Promise.all([ context.waitForEvent('page'), page.getByTestId('user-row-1').getByRole('link').click(), ]); await expect(popup.getByTestId('user-name')).toBeVisible(); // Do work in popup await popup.getByRole('button', { name: 'Edit' }).click(); });

Device Emulation and Geolocation

import { devices } from '@playwright/test'; // In playwright.config.ts — use device descriptors { name: 'Pixel 5', use: { ...devices['Pixel 5'] } }, { name: 'iPhone 14', use: { ...devices['iPhone 14 Pro'] } }, // In a specific test — create mobile context test('mobile checkout flow', async ({ browser }) => { const context = await browser.newContext({ ...devices['Galaxy S21'], locale: 'en-US', timezoneId: 'America/New_York', geolocation: { latitude: 40.7128, longitude: -74.006 }, permissions: ['geolocation'], }); const page = await context.newPage(); await page.goto('/store-locator'); await expect(page.getByTestId('nearest-store')).toBeVisible(); }); // Viewport resize mid-test await page.setViewportSize({ width: 375, height: 812 }); // iPhone // Color scheme emulation await page.emulateMedia({ colorScheme: 'dark' }); await page.emulateMedia({ reducedMotion: 'reduce' });

Visual Regression Testing

// Screenshot comparison — creates baseline on first run test('homepage visual check', async ({ page }) => { await page.goto('/'); await expect(page).toHaveScreenshot('homepage.png'); }); // Component-level screenshot test('button states', async ({ page }) => { const button = page.getByRole('button', { name: 'Submit' }); await expect(button).toHaveScreenshot('submit-button.png'); await page.getByLabel('Email').fill('test@test.com'); await expect(button).toHaveScreenshot('submit-button-active.png'); }); // With threshold (allow small pixel differences) await expect(page).toHaveScreenshot('page.png', { maxDiffPixels: 100, threshold: 0.2, // 20% per-pixel tolerance }); // Update baselines when design changes npx playwright test --update-snapshots // Baseline files stored in: // tests/homepage.spec.ts-snapshots/homepage-chromium-linux.png

Visual baselines are browser + OS specific. Generate them in CI and commit to git for consistent comparison.
