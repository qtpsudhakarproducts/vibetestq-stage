  • Full codebase context — not just open file
  • Composer: multi-file edit from one prompt
  • Agent mode: autonomously browses code
  • Ask about any file: "explain LoginPage.ts"

  • Tab-complete with multi-line awareness

Model Context Protocol (MCP)

What is MCP?

  • Open standard by Anthropic (Nov 2024)
  • Connects AI agents to tools and data sources
  • Like a plugin system for LLMs
  • AI can call external APIs, read files, run commands
  • Playwright MCP gives AI browser control

Playwright MCP Server

  • Claude/Cursor connects to your browser
  • Navigate, click, fill forms autonomously
  • Inspect elements and generate locators
  • Record user flows into test scripts
  • Run tests and report results in chat
// Install Playwright MCP server npm install -g @playwright/mcp // Add to Claude Desktop or Cursor mcp.json { "mcpServers": { "playwright": { "command": "npx", "args": ["@playwright/mcp", "--browser", "chromium"] } } } // Now AI can: "Go to login page, inspect the form, write a LoginPage POM"
