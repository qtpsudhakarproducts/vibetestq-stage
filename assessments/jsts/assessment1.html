Assessment 1

Variables, Types & Operators

Assessment Completed!

0/20


1.Which keyword is used to declare a variable that cannot be reassigned?

const creates a read-only reference to a value. It cannot be reassigned after the initial assignment.

2.What will be the output of console.log(typeof null);?

This is a long-standing bug in JavaScript where typeof null returns "object".

3.Which of the following is NOT a primitive data type in JavaScript?

Arrays and Objects are NOT primitive types; they are reference types.

4.What is the difference between == and ===?

Strict equality (===) ensures that both the value and the data type match exactly.

5.Which of these values is considered "falsy" in JavaScript?

Falsy values include false, 0, "", null, undefined, and NaN.

6.What is the correct way to embed a variable name into a string?

Template literals (using backticks) allow for variable interpolation using ${expression}.

7.What does let x = 5 + "5"; result in?

JavaScript performs string concatenation when a number is added to a string.

8.Which operator is used to find the remainder of a division?

The modulo operator (%) returns the remainder after division.

9.What is the result of !!"" (Double NOT on empty string)?

Empty string is falsy. One `!` makes it true, the second `!` makes it false.

10.In the ternary operator condition ? A : B, which part executes if the condition is false?

The colon separates the value-if-true from the value-if-false.

11.Which variable declaration has "block scope"?

Modern let and const are scoped to the nearest curly braces {}.

12.What will console.log(0.1 + 0.2 === 0.3) output?

Due to floating point precision, 0.1 + 0.2 is actually 0.30000000000000004.

13.Which operator is used as a logical "AND"?

The double ampersand && is the logical AND operator.

14.What does "Hoisting" refer to in JavaScript?

Hoisting allows you to use functions or variables (with var) before they are declared.

15.What is the result of true || false?

The logical OR (||) returns true if AT LEAST ONE operand is true.

16.How would you check if a variable str includes the word "Test"?

.includes() is the modern ES6 method to check for substrings.

17.What will console.log(Boolean("false")); output?

Any non-empty string, even if it says "false", is "truthy" in JavaScript.

18.Which statement correctly compares two values for "Not Equal" strictly?

!== is the strict not-equal operator that checks both value and type.

19.What is the "short-circuit" behavior of the && operator?

In an AND operation, if the first part is already false, the whole expression MUST be false.

20.What is the result of Number("123abc")?

The Number() function returns NaN if the string cannot be converted to a clean number.
