## Job Description
We are seeking a Mid-Level LLM Quality Engineer who has deep expertise in testing Large Language Models, RAG (Retrieval-Augmented Generation) systems, and AI-powered conversational applications. You will design evaluation harnesses, define quality benchmarks, and ensure that LLM outputs meet accuracy, safety, relevance, and reliability standards before reaching production.

## Responsibilities
- Design and execute LLM evaluation test suites measuring accuracy, coherence, relevance, toxicity, and hallucination rates
- Build automated evaluation pipelines using RAGAS, DeepEval, or LangSmith to continuously assess model quality
- Perform adversarial prompt testing including jailbreak attempts, prompt injection, and data leakage scenarios
- Test RAG pipeline components: document ingestion, chunking, embedding quality, retrieval relevance, and answer grounding
- Validate AI agent behavior across multi-turn conversations, tool calls, and error handling
- Evaluate LLM outputs using LLM-as-Judge techniques with calibrated evaluation rubrics
- Define and maintain LLM quality benchmarks and regression test datasets (golden datasets)
- Test LLM API integrations for latency, rate limits, error handling, and output consistency
- Collaborate with AI engineers, product managers, and data scientists to define acceptance criteria for AI features
- Detect and document bias, fairness issues, and harmful content patterns in model outputs
- Integrate LLM evaluation into CI/CD pipelines to enable continuous quality assessment
- Monitor production LLM performance and investigate quality regressions through observability platforms
- Create comprehensive quality reports covering AI-specific dimensions: faithfulness, answer relevancy, context recall

## Qualifications
- Bachelor's or Master's degree in Computer Science, Data Science, NLP, or related field
- 3-6 years of experience in software testing, with 1-2 years specifically in AI/LLM testing
- Strong Python programming skills (scripting, API integration, data processing)
- Hands-on experience with LLM APIs (OpenAI, Anthropic Claude, Google Gemini, or open-source LLMs)
- Familiarity with evaluation frameworks: RAGAS, DeepEval, Promptfoo, or similar
- Understanding of RAG architecture and vector databases
- Knowledge of NLP concepts: tokenization, embeddings, semantic similarity
- Experience with API testing tools (Postman, pytest, requests)
- Understanding of AI safety, bias, and responsible AI principles
- Excellent analytical thinking and documentation skills
- Experience with LangChain, LlamaIndex, or similar LLM orchestration frameworks is a plus

## LLM Quality Dimensions to Master
| Quality Dimension | Measurement Approach |
|---|---|
| Faithfulness | Answer grounded in context, no hallucination |
| Answer Relevancy | Response addresses the actual question |
| Context Precision | Retrieval quality in RAG pipelines |
| Context Recall | Coverage of relevant context chunks |
| Toxicity & Safety | Harmful content detection rates |
| Bias & Fairness | Differential performance across demographics |
| Latency & Consistency | Response time and output stability |
