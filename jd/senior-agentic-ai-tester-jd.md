## Job Description
We are seeking a Senior Agentic AI Tester who will pioneer quality engineering for the most cutting-edge AI systems: autonomous agents. As AI systems increasingly take autonomous actions — browsing the web, writing and executing code, managing files, calling external APIs — ensuring their safety, correctness, and reliability is critical. You will design entirely new testing methodologies for agentic AI systems that have never been built before.

## Responsibilities
- Design and execute comprehensive test strategies for AI agents: single-agent, multi-agent, and hierarchical agent systems
- Test agent tool-use capabilities: validate that agents correctly invoke tools, pass correct parameters, and handle tool errors gracefully
- Design agentic workflow test scenarios: multi-step task completion, long-horizon reasoning, goal decomposition correctness
- Perform adversarial testing against agent systems: goal hijacking, memory poisoning, indirect prompt injection chains, tool misuse
- Test agent memory systems: validate short-term context window management, long-term memory retrieval, and episodic memory consistency
- Evaluate multi-agent orchestration: communication protocols, task delegation, conflict resolution, and emergent behavior testing
- Build agent simulation environments and sandboxes for safe adversarial testing without production impact
- Test MCP (Model Context Protocol) server integrations: tool discovery, execution, error handling, and security boundaries
- Define and validate agent safety boundaries: containment testing, least-privilege tool access verification, and human-in-the-loop checkpoint testing
- Perform chaos engineering for agents: simulate LLM API failures, tool timeouts, malformed tool responses, and network disruptions
- Analyze agent execution traces using LangSmith or custom logging to identify failure patterns and quality issues
- Create benchmark suites for agent task completion: domain-specific agent evaluation with ground truth scoring
- Collaborate with AI safety researchers on containment, alignment, and value alignment testing
- Establish agentic AI quality standards for the organization including testing checklists and risk assessment frameworks
