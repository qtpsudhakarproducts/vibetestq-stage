## Job Description
We are looking for a motivated Junior AI-Augmented QA Engineer who embraces AI tools as a core part of their testing workflow. This role is designed for testers who use AI copilots to write test cases, generate automation scripts, analyze logs, and accelerate defect detection. You will work at the intersection of modern QA practices and the rapidly evolving AI toolchain.

## Responsibilities
- Use AI copilots (GitHub Copilot, Cursor, Tabnine) to generate, review, and refine automated test scripts
- Leverage ChatGPT, Claude, or Gemini to design test cases from requirements, user stories, and acceptance criteria
- Write and execute manual and automated tests with AI assistance for web, mobile, and API applications
- Use AI-powered test platforms (e.g., Testim, Mabl, Applitools) for visual regression and self-healing tests
- Assist in prompt engineering to create high-quality test inputs and exploratory testing heuristics
- Report and document defects using AI-assisted templates for clarity and completeness
- Participate in AI SDLC workflows — from AI-generated requirements review to AI code review testing
- Collaborate with developers and senior QA to improve coverage using AI-generated edge cases
- Learn and apply AI-powered tools for log analysis, root cause identification, and test data generation
- Maintain basic automation suites and contribute to test repositories using Git

## Qualifications
- Bachelor's degree in Computer Science, Engineering, Information Technology, or related field
- 0-2 years of experience in software testing or QA
- Hands-on exposure to AI coding assistants (GitHub Copilot, Cursor, or equivalent)
- Basic knowledge of programming: Python or JavaScript
- Familiarity with Playwright, Cypress, or Selenium
- Understanding of SDLC, Agile methodologies, and testing fundamentals
- Curiosity about AI tools and eagerness to experiment with emerging AI testing platforms
- Good communication skills and ability to articulate test coverage needs
