## Description
We are seeking a Senior Software Development Engineer in Test (SDET) to join our team and drive the quality and automation of our software products in the AI era. The ideal candidate will have extensive experience in test automation and framework development, with a strong focus on AI-augmented testing practices. You will architect intelligent testing systems, validate AI-powered features, and integrate AI quality gates into CI/CD pipelines while mentoring teams on AI tool adoption.

## Responsibilities
- Architect and build AI-augmented test automation frameworks using GitHub Copilot, Cursor, and LLM-assisted code generation
- Design and implement self-healing test frameworks (Testim, Healenium, Mabl) to reduce automation maintenance overhead
- Use LLMs (GPT-4, Claude) to generate comprehensive test suites from specifications, API contracts, and user stories
- Implement AI-driven CI/CD quality gates: intelligent test selection, ML-based flake detection, and anomaly-based alerting
- Lead quality validation for AI-powered features: test LLM integrations, RAG pipelines, AI APIs, and GenAI feature quality
- Develop prompt engineering workflows for automated test generation, root cause analysis, and defect reporting
- Design and execute API testing strategies for both traditional and AI model inference endpoints
- Perform comprehensive testing including API, performance, security, and integration testing
- Collaborate with development and ML teams in Agile/Scrum to ensure testability and quality throughout the AI SDLC
- Analyze test results using AI-powered analytics and produce quality trend insights
- Mentor junior and mid-level SDETs on AI tool adoption, prompt engineering, and AI testing practices
- Integrate security testing including OWASP LLM Top 10 review and AI attack surface testing
- Participate in code reviews with focus on code quality, testability, and AI-readiness
- Stay current on AI testing tools, LLM evaluation frameworks, and emerging AI quality methodologies

## Qualifications

- Proficiency in programming languages: Java, Python, JavaScript, Kotlin

- Knowledge of CI/CD tools: Jenkins, GitHub Actions, Azure DevOps, Bitbucket

- Experience with databases: SQL, Oracle, SQLite, and data management
- Understanding of cloud platforms, microservices, and API testing

- Strong analytical and problem-solving abilities
- Experience with security testing, performance testing, and vulnerability management is a plus
- ISTQB or equivalent certification preferred
