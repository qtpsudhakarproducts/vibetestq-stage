## Job Description
We are looking for a Mid-Level MLOps QA Engineer who brings quality engineering discipline to machine learning operations. You will embed quality gates across the entire ML lifecycle — from data ingestion and feature engineering to model training, evaluation, deployment, and production monitoring. This role is at the critical intersection of QA, data engineering, and ML engineering.

## Responsibilities
- Design and implement quality gates across ML pipelines: data ingestion → feature engineering → model training → evaluation → deployment
- Validate training data quality using frameworks like Great Expectations or Deequ (completeness, consistency, distribution checks)
- Test ML model evaluation pipelines — verify that metrics (accuracy, F1, AUC) are correctly computed and benchmarked
- Validate model registry workflows: versioning, artifact storage, model lineage, and experiment tracking in MLflow or DVC
- Test model serving APIs (REST/gRPC inference endpoints) for correctness, latency SLAs, and error handling
- Implement CI/CD quality checks in ML pipelines using ZenML, Kubeflow, or SageMaker Pipelines
- Monitor production model behavior for data drift, concept drift, and performance degradation using Evidently AI or WhyLabs
- Validate A/B testing setups and shadow deployment pipelines for safe model rollout
- Test feature stores for consistency between training and serving environments (training-serving skew detection)
- Collaborate with data scientists and ML engineers to define testability requirements for ML models
- Build automated regression testing for model quality: validate that new model versions do not degrade benchmark performance
- Test infrastructure as code for ML (Terraform/Helm charts for ML serving infrastructure)
- Document ML-specific defects: data issues, model quality regressions, pipeline failures, serving errors
