## Description
We are looking for an experienced Lead Software Development Engineer in Test (SDET) to lead our testing automation efforts and drive quality engineering practices. The ideal candidate will have strong programming skills, expertise in test automation frameworks, and experience leading SDET teams. This role involves designing scalable test automation solutions, mentoring team members, and collaborating with development teams to ensure high-quality software delivery.

## Responsibilities
- Lead and mentor SDET teams on AI-augmented testing practices, GitHub Copilot adoption, and AI tool integration
- Architect AI-native test automation ecosystems: self-healing frameworks, AI-generated test suites, intelligent CI/CD quality gates
- Design and implement GenAI-powered test generation pipelines converting PRDs and API specs into executable test suites
- Own quality validation strategy for AI-powered features: LLM integrations, AI APIs, ML model endpoints, and agentic workflows
- Implement AI-powered CI/CD quality gates: intelligent test selection, ML flake detection, and anomaly-based alerting
- Lead responsible AI testing: coordinate safety, bias, and fairness validation for AI features
- Develop automated test scripts for web, mobile, and API testing with AI assistance
- Perform code reviews for AI-generated and human-written test code with focus on quality and coverage
- Analyze test results using AI-powered analytics and provide insights for quality improvement
- Research, evaluate, and implement emerging AI testing tools and platforms
- Lead performance, load, and security testing including AI service performance benchmarking
- Build AI testing playbooks and standards for the SDET organization
- Contribute to test strategy and planning for complex AI-powered projects
- Foster a culture of AI-augmented quality and continuous improvement
- Define AI quality metrics, OKRs, and reporting dashboards for SDET leadership
