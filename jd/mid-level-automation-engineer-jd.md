## Job Description
We are looking for a Mid-level Automation Engineer to design, develop, and maintain automated test frameworks. The role involves creating efficient automation scripts to ensure software quality and reliability across various platforms.

## Responsibilities
- Design and develop automated test frameworks using AI coding assistants (GitHub Copilot, Cursor)
- Use LLMs (GPT-4, Claude) to generate test scripts from requirements and API specs
- Implement self-healing automation using AI platforms (Healenium, Testim, Mabl)
- Execute automated test suites and analyze results with AI-powered insights
- Collaborate with development teams to integrate testing into CI/CD pipelines
- Maintain and update automation infrastructure including AI-generated test suites
- Perform API and UI automation testing for both traditional and AI-powered features
- Test AI-integrated features: validate LLM API endpoints, AI service responses, and model outputs
- Debug and troubleshoot automation issues with AI-assisted root cause analysis
- Document automation processes, AI tool usage, and best practices
- Participate in code reviews and provide feedback on testability and AI-readiness
- Experiment with and adopt emerging AI testing platforms and tools

## Qualifications

- 3-6 years of experience in automation testing
- Proficiency in programming languages like Java or Python
- Experience with automation tools such as Selenium, Playwright, or Cypress
- Knowledge of testing frameworks and CI/CD tools
- Strong analytical and problem-solving skills
- Familiarity with version control systems like Git
- Good communication and teamwork abilities
