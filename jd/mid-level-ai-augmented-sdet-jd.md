## Job Description
We are seeking a Mid-Level AI-Augmented SDET who can leverage cutting-edge AI tools to design, build, and maintain intelligent test automation frameworks. You bring a developer mindset combined with AI proficiency to dramatically accelerate test coverage, reduce maintenance burden through self-healing tests, and integrate AI quality gates into CI/CD pipelines.

## Responsibilities
- Design and build AI-augmented test automation frameworks using Playwright or Cypress, powered by GitHub Copilot and LLM assistance
- Implement self-healing automation using AI-powered platforms (Testim, Mabl, Healenium)
- Use generative AI (GPT-4, Claude) to generate comprehensive test case suites from PRDs, user stories, and API contracts
- Integrate AI anomaly detection in CI/CD pipelines to surface test flakiness and regressions intelligently
- Develop prompt engineering workflows for automated test generation, bug report creation, and root cause analysis
- Collaborate with ML/data engineering teams to test AI-feature APIs and validate model integration points
- Build AI-assisted performance testing strategies and interpret AI-generated reports
- Create AI-powered test data factories using GenAI for edge case and boundary value generation
- Mentor junior AI-Augmented QA engineers on AI tool adoption and best practices
- Implement quality gates in AI SDLC pipelines covering requirements validation, code review, and deployment checks
- Contribute to test strategy for AI-powered product features (chatbots, recommendation engines, GenAI features)
- Track AI tool effectiveness metrics: test generation time, automation coverage uplift, defect escape rate
