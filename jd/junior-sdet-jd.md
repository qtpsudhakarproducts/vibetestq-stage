## Job Description
We are looking for a Junior SDET to join our development team and contribute to the quality assurance of our software products. This role focuses on developing and maintaining automated test frameworks, writing test scripts, and ensuring the reliability of applications through comprehensive testing strategies.

## Responsibilities
- Develop and maintain automated test scripts and frameworks using GitHub Copilot and AI coding assistants
- Use AI tools (ChatGPT, Claude) to generate test cases, test data, and automation scripts from requirements
- Perform API testing, database testing, and backend testing
- Test AI-integrated features: validate chatbot responses, AI-powered search, and recommendation engine outputs
- Collaborate with developers to understand code changes and create appropriate tests
- Execute automated test suites and analyze test results
- Identify and report bugs with AI-enhanced defect descriptions, and work with teams to resolve issues
- Participate in code reviews and provide feedback on testability
- Assist in continuous integration and deployment processes
- Learn and apply AI testing tools and methodologies (Mabl, Testim, Applitools)
- Document test procedures and maintain test environments
- Practice prompt engineering to improve test generation quality with AI tools

## Qualifications
- Bachelor's degree in Computer Science, Engineering, or related field
- 0-2 years of experience in software testing or development
- Basic knowledge of programming languages like Java, Python, or JavaScript
- Familiarity with automation tools such as Selenium, Playwright, or Cypress
- Understanding of testing methodologies and SDLC
- Strong analytical and problem-solving skills
- Good communication and teamwork abilities
- Knowledge of version control systems like Git is a plus
