## Job Description
We are seeking an experienced Mid-level Manual Tester to join our quality assurance team. The role involves executing comprehensive manual testing processes to ensure the delivery of high-quality software products. You will work closely with development teams to identify and resolve issues.

## Responsibilities
- Execute manual test cases and document test results using AI-augmented workflows
- Use AI tools (ChatGPT, Claude) to generate comprehensive test scenarios from requirements and user stories
- Perform functional, regression, exploratory, and user acceptance testing
- Test AI-powered product features: validate LLM chatbot responses, recommendation outputs, AI search quality
- Evaluate AI feature outputs for accuracy, relevance, hallucination, and consistency
- Identify, report, and track software defects with AI-enhanced defect descriptions
- Collaborate with developers and stakeholders to understand requirements
- Apply prompt engineering to design adversarial test inputs for AI features
- Participate in test planning and strategy development
- Analyze test results and provide detailed reports covering AI quality dimensions
- Ensure adherence to testing standards and best practices
- Assist in automation testing using AI-assisted script generation where applicable
- Maintain test documentation, environments, and AI test data repositories
