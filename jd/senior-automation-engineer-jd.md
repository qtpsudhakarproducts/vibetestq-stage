## Description
We are looking for a Senior Automation Engineer to design, develop, and maintain automated testing frameworks and solutions. The ideal candidate will have extensive experience in test automation tools and frameworks, with a focus on improving efficiency and reliability of software testing processes. You will collaborate with development and QA teams to implement robust automation strategies across various platforms and technologies.

## Responsibilities
- Architect and build AI-native test automation frameworks using Playwright, Selenium, or UiPath, enhanced by GitHub Copilot and LLM assistance
- Design and implement self-healing automation frameworks (Testim, Healenium, Mabl) for large-scale test suite maintenance
- Use LLMs (GPT-4, Claude) to generate comprehensive test suites from PRDs, API contracts, and design specifications
- Implement AI-driven CI/CD quality gates: intelligent test selection, ML-based flake detection, and anomaly alerting
- Lead quality validation for AI-powered product features: test LLM integrations, AI API endpoints, and GenAI feature workflows
- Perform advanced API testing, including AI model endpoints (REST/gRPC inference), validating output correctness and latency
- Integrate automation with cloud platforms (AWS, Azure, GCP) including cloud AI services (SageMaker, Azure AI, Vertex AI)
- Define and implement prompt engineering workflows for test generation, bug report automation, and root cause analysis
- Mentor junior and mid-level engineers on AI tool adoption, prompt engineering, and AI testing practices
- Analyze test results using AI-powered analytics and produce quality trend reports
- Build AI-powered performance testing strategies and interpret AI-generated load insights
- Contribute to responsible AI testing: test AI features for bias, safety, and content appropriateness
- Participate in code reviews with focus on both code quality and AI feature testability
- Evaluate and recommend emerging AI testing tools, platforms, and methodologies
