## Job Description
We are seeking a Mid-level SDET to design, develop, and execute automated tests for software applications. The role involves working closely with development teams to ensure high-quality code through comprehensive testing strategies.

## Responsibilities
- Develop and maintain automated test scripts and frameworks using GitHub Copilot and AI code generation
- Use LLMs (GPT-4, Claude) to generate test cases, test data, and API test scenarios
- Implement self-healing automation using AI platforms to reduce maintenance overhead
- Perform unit, integration, and regression testing with AI-assisted coverage analysis
- Collaborate with developers to integrate AI quality gates into CI/CD pipelines
- Analyze test results with AI-powered analytics and report defects with enhanced context
- Test AI-integrated product features: validate LLM APIs, AI model service endpoints, and AI-powered workflows
- Design test cases and scenarios for new AI features including chatbots and recommendation engines
- Participate in code reviews and provide testing feedback including AI-readiness assessment
- Maintain test environments and AI testing tool infrastructure
- Ensure test coverage and quality metrics are maintained for AI-powered features
- Learn and apply responsible AI testing principles: bias detection, hallucination testing
