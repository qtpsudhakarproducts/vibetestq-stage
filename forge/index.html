What Forge holds

Everything a release is judged on.

Test cases

A versioned library

Folders, drafts and accepted versions, steps tables or Gherkin. Import from TestRail, Xray or a file.

Test cycles

A release or a sprint

The tests chosen, who runs them, their results, readiness and sign-off.

Executions

Every result

From people and from CI, with its steps, evidence and defects.

Reports

Reports and traceability

Predefined and saved reports, published snapshots, and requirements traced to tests and results.

Changes

Each pull request

What ran in CI, what failed, and any test that was weakened.

Dashboard

Where the project stands

Your work, the active cycles, failures and coverage. Every number opens the records it counts.

With your coding agent

It drafts and links.
You decide.

Forge is an MCP server: connect the coding agent your team already uses, and it can read the project's test cases, draft new ones and link tests to them. Nothing an agent drafts counts until a person accepts it.
