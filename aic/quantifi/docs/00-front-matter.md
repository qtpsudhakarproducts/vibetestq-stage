## About This Guide

This guide accompanies the 15-day Playwright GenAI training program delivered at Quantifi. Each chapter maps directly to one day of training. The trainer covers the topic for 2 hours, and participants then apply what they learned in the 1-hour hands-on assignment.

The guide follows a single, consistent pattern across all chapters:

1. **What You Will Learn** — the skills covered that day
2. **Concept Sections** — clear explanations with code examples
3. **Interview Questions** — exam-style questions to test understanding

All Playwright automation days use the OrangeHRM demo application as the test target:

- **URL:** `https://opensource-demo.orangehrmlive.com`
- **Username:** `Admin`
- **Password:** `admin123`
