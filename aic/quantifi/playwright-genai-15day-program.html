Program Overview

This intensive 15-day training program has been customized specifically for Quantiphi's requirements and timelines, delivering comprehensive Playwright automation with AI-enhanced testing capabilities. The curriculum progresses strategically: JavaScript/TypeScript foundations (3 days), Playwright Core Library (3 days), Test Framework (1 day), AI IDEs & MCP Agents (2 days), API Testing (1 day), POM Framework & Automation Libraries (2 days), BDD with Cucumber (1 day), AWS CodeBuild CI/CD & Reporting (1 day), and Capstone Project (1 day). With 3-hour daily sessions (2 hours instruction + 1 hour practice), Quantiphi team members will gain practical skills to immediately apply modern automation practices in their projects.

Lab Environment & System Requirements

Hardware Requirements

  • Laptop/Desktop: Windows 10/11, macOS 11+, or Linux (Ubuntu 20.04+)
  • Processor: Minimum Intel i5 or equivalent (i7 or higher recommended)
  • RAM: Minimum 8GB (16GB recommended for parallel test execution)
  • Storage: Minimum 10GB free disk space (SSD recommended)
  • Display: Minimum 1366x768 resolution (1920x1080 recommended)
  • Internet: Stable broadband connection (minimum 10 Mbps)

Required System Permissions

  • Administrator Rights: Required for installing Node.js, VS Code, and browsers
  • Firewall Permissions: Allow outbound connections on ports 80, 443, 3000-9223
  • Antivirus Exclusions: Add project folders to antivirus whitelist (if applicable)
  • Proxy Configuration: Corporate proxy settings configured for npm and Git
  • Execution Policy (Windows): PowerShell execution policy set to RemoteSigned

Software Installation Permissions

  • Permission to install Node.js LTS (v18.x or v20.x)
  • Permission to install Visual Studio Code (latest version)
  • Permission to install Git (latest version)
  • Permission to download and install browser binaries (Chromium, Firefox, WebKit)
  • Permission to install VS Code extensions from marketplace
  • Permission to install global npm packages

Cloud & External Access

  • AWS Account: Access to AWS Console (IAM permissions for CodeBuild, S3)
  • GitHub Account: For repository access and GitHub Actions (optional)
  • AI API Access: API keys for OpenAI, Claude, or Gemini (will be provided)
  • Report Portal: Access to Report Portal instance (will be set up)
  • Network Access: Ability to access external APIs and npm registry

Pre-Training Setup (Recommended)

  • Install Node.js LTS from nodejs.org
  • Install Visual Studio Code from code.visualstudio.com
  • Install Git from git-scm.com
  • Verify Node.js installation: node --version and npm --version
  • Configure Git with username and email
  • Create a dedicated folder for training materials (ensure write permissions)
  • Test npm installation: npm install -g npm@latest

Corporate Environment Considerations

  • IT Approval: Obtain necessary approvals before training starts
  • Proxy Settings: Configure npm proxy if behind corporate firewall
  • VPN Access: Ensure VPN allows access to required cloud services
  • Port Restrictions: Request IT to open required ports if blocked
  • Certificate Issues: Configure npm to work with corporate SSL certificates
  • Package Registry: Access to npmjs.com or internal npm registry

Lab Environment Verification

  • Pre-training system check will be conducted on Day 1
  • Trainer will provide setup assistance if needed
  • Backup cloud environment available if local setup faces issues
  • All software and tools will be verified during initial setup session
