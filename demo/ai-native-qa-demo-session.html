How Playwright Evolved: 4 Phases

Playwright transformed from a script runner to the infrastructure AI operates — this happened in 4 distinct phases

1
Deterministic Automation (2020–2024) — Humans write scripts, Playwright executes. Reliable, but coverage bounded by imagination. Tests encode implementation, not intent.
Script Era
2
AI-Assisted Testing (2024–Early 2025) — AI generates tests from natural language. But humans still ran Playwright. Testing was still a separate phase after development.
AI Assist
3
MCP Disruption (March 2025 · v1.52) — AI now directly operates Playwright via Model Context Protocol. AI interacts with the accessibility tree, observes results, decides next steps. Playwright became callable infrastructure for AI.
MCP Era
4
Agentic Playwright (Oct 2025 · v1.56 → 1.59) — Planner/Generator/Healer agents + VS Code integration. Testing is now a continuous intelligence layer. Not a phase — a system that runs while you build.
Agentic Era

New Skills the 4 Phases Demand from QA

Each phase shift added a new skill layer — QA must master all four to stay relevant

1
Phase 1 — Script Era: Understand what Playwright executes. Know locators, assertions, waits. Read and validate test code.
2
Phase 2 — AI-Assisted: Prompts & context engineering. Use VS Code + GitHub Copilot. Generate and review AI-produced test cases and Gherkin feature files.
3
Phase 3 — MCP Era: Configure MCP servers. Use Claude Desktop + Playwright MCP for live app exploration. Structured exploration capture & toolkit organisation.
4
Phase 4 — Agentic Era: Govern Planner, Generator & Healer agents. Design the AI-Native SDLC & STLC. Apply the parallel stream model. Be the Quality System Architect — not just the executor.

  None of these skills are taught in standard Playwright tutorials — this is exactly the gap this program fills
