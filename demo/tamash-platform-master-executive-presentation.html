Runtime Self-Healing

tamash-playwright

Autonomous Runtime Self-Healing & AST Code Patching Engine

tamash-playwright: 4-Tier Healing & Non-Invasive Assertions

Tier 1

Accessibility

Matches ARIA tree, roles, and accessible names. Free, 0-token instant resolution.

Tier 2

Multimodal

Analyzes visual layout geometry and bounding box proximity relative to containers.

Tier 3

Fuzzy Lexical

Levenshtein distance matching button text variations, casing, and placeholder shifts.

Tier 4

System One AI

Narrow semantic judgement when confidence ≥ 0.80. Falls back safely if uncertain.

The Non-Invasive Assertion Guarantee: Heals actions (clicks, fills) but NEVER touches assertions (expect). Zero false passes allowed.
