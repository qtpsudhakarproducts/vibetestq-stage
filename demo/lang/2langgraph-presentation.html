Why LangGraph? — When Chains Aren't Enough

❌ LangChain chains are linear:

  • No loops — can't retry a failing step
  • No branching — can't take different paths
  • No state — each chain call starts fresh
  • No human checkpoints mid-workflow

✅ LangGraph adds:

  • Persistent state across all steps
  • Conditional edges (branch by result)
  • Cycles — loop until a condition is met
  • Human-in-the-loop checkpoints
  • Parallel execution of independent agents

Think of LangGraph as the CI/CD pipeline for your AI agents — with retry logic, gates, and parallel steps.

The 3 Core Concepts: State, Nodes, Edges

State

A TypeScript object passed between every step. Nodes read from it and write to it. The entire workflow history lives here.

interface QAState { bugReport: string; severity: string; rootCause: string; approved: boolean; }

Nodes

Async functions that take state, do work (call an LLM, run a tool, query a DB), and return partial state updates.

async function classifyBug(state) { const severity = await llm.classify( state.bugReport ); return { severity }; }

Edges

Connections between nodes. Can be simple (always go to X) or conditional (go to X if approved, go to Y if rejected).

// Conditional edge graph.addConditionalEdge( "review", (state) => state.approved ? "close" : "escalate" );

Cycles, Parallel Execution & Human-in-the-Loop

The patterns that make LangGraph uniquely powerful for QA automation

Cycles — Retry Until the Quality Bar is Met

A cycle is an edge that goes backwards — creating a retry loop. Essential for quality gates in AI workflows.

QA Pattern: Generate → Evaluate → Retry

function shouldRetry(state: QAState) { // Loop back if test cases are < threshold if (state.qualityScore < 0.8) { return "generate"; // back to start } if (state.iterations >= 3) { return END; // safety limit } return "approve"; // move forward } graph.addConditionalEdges( "evaluate", shouldRetry );

Real QA Use Cases for Cycles:

  • Generate test cases until coverage threshold is reached
  • Retry selector healing until the locator is valid
  • Re-analyse a bug report if root cause confidence is low
  • Refine test data until all constraints pass validation

Always set a max iterations limit

Without a safety limit, cycles can run indefinitely if the quality threshold is never met.

Conditional Branching — Different Paths for Different Results

function routeByTestResult(state: TestState) { switch (state.testResult) { case "PASS": return "logSuccess"; case "FAIL": return "analyseFailure"; case "FLAKY": return "detectFlakiness"; default: return "manualReview"; } } graph.addConditionalEdges( "runTest", routeByTestResult, { logSuccess: "logSuccess", analyseFailure: "analyseFailure", detectFlakiness: "detectFlakiness", manualReview: "manualReview" } );

Human-in-the-Loop — Pause, Review, Resume

LangGraph can pause the workflow at any node, wait for human input, then resume from exactly where it stopped.

QA Use Cases:

  • AI generates test cases → QA lead approves before execution
  • Agent finds a P0 bug → engineer confirms before auto-filing
  • AI suggests selector fix → dev approves before merge
  • Automated report drafted → manager reviews before send

How it works:

Use interrupt_before to pause at a node. State is checkpointed. A human provides input. The graph resumes from the interrupt point with updated state.

// Compile with checkpointer for persistence const app = graph.compile({ checkpointer: new MemorySaver(), interrupt_before: ["humanApproval"] }); // Phase 1: Run until interruption const config = { configurable: { thread_id: "bug-001" } }; await app.invoke({ bugReport }, config); // Workflow pauses here — human reviews // Phase 2: Human provides decision await app.updateState(config, { humanDecision: "approved", humanComment: "P1, assign to payments team" }); // Phase 3: Resume from interrupt await app.invoke(null, config);

Multi-Agent QA System with LangGraph

A supervisor agent delegates tasks to specialist agents — just like a QA lead coordinates a testing team.

QA Supervisor Agent

Receives a testing goal. Breaks it into sub-tasks. Delegates to specialists. Monitors progress. Synthesises the final report.

Test Generator Agent

Reads requirements. Generates test cases using LangChain chains. Returns structured test plan JSON.

Playwright Runner Agent

Executes the Playwright tests. Captures results, screenshots, and trace files. Returns structured results.

Bug Analyst Agent

Analyses failures. Classifies root cause. Suggests fixes. Files structured defect reports.

Coverage Reporter Agent

Calculates coverage metrics. Identifies gaps. Generates the executive test summary.

All coordinated by the Supervisor through LangGraph state

Key Takeaways — LangGraph for QA

What LangGraph adds to LangChain:

  • Stateful workflows — context persists across all steps
  • Loops and retry — quality gates with iteration limits
  • Conditional branching — different paths by result
  • Human-in-the-loop — pause → review → resume
  • Parallel execution — fan-out multiple agents
  • Multi-agent supervision — delegate and orchestrate

QA workflows to build with LangGraph:

  • End-to-end test lifecycle pipeline
  • Playwright test with AI failure analysis
  • Multi-agent: generate → execute → report
  • Bug triage with human approval gate

Start with LangChain first

Learn to build single-step chains well. Use LangGraph only when your workflow needs loops, branching, or multiple coordinated agents.
