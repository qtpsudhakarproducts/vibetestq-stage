Software Development Life Cycle

The blueprint for building software, from idea to release.

Traditional (Waterfall)

Linear & Rigid. Like building a house.

  • Reqs -> Design -> Code -> Test -> Deploy
  • Testing happens at the end.
  • Risk: Late bug discovery.

Modern (Agile)

Iterative & Flexible. Like a food truck menu.

  • Sprints (2-week cycles).
  • Continuous Testing.
  • Benefit: Fast feedback loops.

Phase Shift: In the AI Era, we move to AI-SDLC where AI agents assist in every single phase of the lifecycle.

Software Testing Life Cycle (STLC)

  1. Requirement Analysis: Understanding "What to test". (AI: Summarize docs)
  2. Test Planning: Strategy & Tools. (AI: Draft Plans)
  3. Test Design: Writing Scenarios/Cases. (AI: Generate Cases)
  1. Execution: Running tests. (AI: Auto-Browsing)
  2. Defect Reporting: Logging bugs. (AI: Auto-Report)
  3. Closure: Synthesis & Sign-off.

STLC runs parallel to SDLC. It ensures that quality is baked in, not just checked at the end.

Testing Types & Hierarchy

Functional

"Does it work?"

  • Unit/Integration
  • System/Regression
  • Smoke/Sanity

Non-Functional

"How well does it work?"

  • Performance (Load)
  • Security (Pen Test)
  • Usability/UX

Approaches

"Visibility of code"

  • Black Box (No code)
  • White Box (Code visible)
  • Gray Box (Hybrid)

Crucial: AI excels at "Checking" (Functional). Humans excel at "Testing" (Exploratory & Usability).

Defect Life Cycle (Bug Life Cycle)

The journey of a bug from discovery to resolution.

NEW OPEN FIXED RETEST CLOSED

Anatomy of a Bug

  • summary: Short title.
  • Steps to Reproduce: Precise instructions.
  • Severity: Impact on business.

Reopening Bugs

If "Retest" fails, the bug goes back to "Open" state. This cycle repeats until quality is met.

The AI Era: What Changed?

Traditional Tester

" The Checker"

  • Manually writing steps.
  • Manually clicking buttons.
  • Focus on execution.

AI Era Tester

"The Quality Orchestrator"

  • Prompts AI to write cases.
  • Uses Agents to execute.
  • Focus on Strategy & UX.

Requirement: Testers now need "Prompt Engineering" skills alongside "Testing Mindset".

The New AI Toolset

Browser Agents

Claude 3.5 Sonnet / Computer Use

Give it a URL and a goal ("Test the checkout flow"), and it clicks/types for you.

MCP Servers

Model Context Protocol

Bridges AI to tools. Allows Claude to access your JIRA, Database, and Playwright directly.

AI IDEs

Cursor / Windsurf

Integrated environments where AI writes test code, fixes bugs, and runs tests.

AI Leverage in Every Phase

  • Analysis: Upload Requirements to AI -> "Find missing edge cases" -> Better Coverage.
  • Design: "Generate Gherkin scenarios for Login" -> Instant Test Cases.
  • Execution: use Browser Assistants to run exploratory charters -> Speed.
  • Reporting: Paste logs into AI -> "Summarize this failure for a Developer" -> Clear Bug Reports.
  • Automation: Use Cursor + Playwright to generate automation scripts from manual steps -> Code Generation.
