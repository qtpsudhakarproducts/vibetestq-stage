What is GitHub Actions?

Definition

GitHub Actions is GitHub's built-in automation platform that runs workflows triggered by events (push, PR, schedule)

The Smart Home Analogy

Without Automation: You manually turn on lights, lock doors, adjust thermostat → 4-5 hours wasted daily

With GitHub Actions: Motion sensor triggers lights, schedule locks doors, temp triggers heat → 70% time saved!

Key Point: GitHub Actions = Your robot assistant that runs tests automatically when code changes

GitHub Actions Architecture

Event: Push/PR/Schedule
Workflow: .github/workflows/test.yml
Job: Runs on Ubuntu/Windows/macOS
Runner: VM provisions (30-60s)
Result: Pass/Fail + Artifacts

Core Concepts

  • Workflow: YAML recipe
  • Event: Trigger alarm
  • Job: One cook/dish
  • Step: Cooking step
  • Runner: Kitchen (VM)
  • Action: Pre-made spice mix

OS CPU RAM Cost

Your First Workflow

# .github/workflows/test.yml name: Run Tests on: [push, pull_request] jobs: test: runs-on: ubuntu-latest steps: - name: Checkout code uses: actions/checkout@v4 - name: Setup Node.js uses: actions/setup-node@v4 with: node-version: '20' - name: Install dependencies run: npm ci - name: Run tests run: npm test

What Happens:

1. You git push → 2. GitHub detects → 3. Provisions Ubuntu VM → 4. Clones repo → 5. Runs steps → 6. Shows results

Playwright Workflow

# .github/workflows/playwright.yml name: Playwright Tests on: [push, pull_request] jobs: test: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Setup Node.js uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - name: Install dependencies run: npm ci - name: Install Playwright browsers run: npx playwright install --with-deps chromium - name: Run Playwright tests run: npx playwright test env: CI: true - name: Upload test report uses: actions/upload-artifact@v4 if: always() with: name: playwright-report path: playwright-report/ retention-days: 30

Key Features

  • npm caching: Speeds up installs (cache: 'npm')
  • Browser auto-install: --with-deps installs system dependencies
  • Artifacts: HTML report saved 30 days, always() runs even on failure

Result: Tests run on every push, HTML report downloadable, screenshots on failure

Multi-Browser Testing

name: Multi-Browser Tests on: [push, pull_request] jobs: test: runs-on: ubuntu-latest strategy: fail-fast: false matrix: browser: [chromium, firefox, webkit] steps: - uses: actions/checkout@v4 - uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - run: npm ci - run: npx playwright install --with-deps ${{ matrix.browser }} - run: npx playwright test --project=${{ matrix.browser }} - uses: actions/upload-artifact@v4 if: always() with: name: report-${{ matrix.browser }} path: playwright-report/
3 Parallel Jobs
Chrome + Firefox + Safari

Multi-OS Testing

strategy: matrix: os: [ubuntu-latest, windows-latest, macos-latest] browser: [chromium, firefox, webkit] exclude: # WebKit doesn't work on Windows - os: windows-latest browser: webkit include: # Safari only on macOS - os: macos-latest browser: safari runs-on: ${{ matrix.os }}

Cost Warning!

10 min Ubuntu = 10 min billed ($0.08)

10 min macOS = 100 min billed ($0.80)

Strategy: Run most tests on Ubuntu, only Safari tests on macOS

Result: 3 OS × 3 browsers = 9 parallel jobs!

Scheduled Tests (Cron)

Cron Syntax Primer

* * * * *
│ │ │ │ │
│ │ │ │ └─ Day of week (0-7, Sun=0 or 7)
│ │ │ └─── Month (1-12)
│ │ └───── Day of month (1-31)
│ └─────── Hour (0-23)
└───────── Minute (0-59)

Common Examples

  • 0 2 * * * → Daily at 2:00 AM
  • 0 9 * * 1 → Every Monday at 9:00 AM
  • 0 6,18 * * * → Twice daily (6 AM & 6 PM)
  • 0 8 * * 1-5 → Weekdays at 8 AM

Use Case: Run regression tests nightly when traffic is low

Nightly Test Workflow

on: schedule: - cron: '0 2 * * *' # 2 AM daily workflow_dispatch: # Manual trigger jobs: nightly-tests: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - run: npm ci - run: npx playwright test - name: Notify on failure if: failure() run: | curl -X POST ${{ secrets.SLACK_WEBHOOK }} \ -d '{"text":"❌ Nightly tests failed!"}'

Result: Tests run automatically every night at 2 AM + Slack alert on failure

Manual Triggers (workflow_dispatch)

on: workflow_dispatch: inputs: environment: description: 'Environment to test' required: true type: choice options: - staging - production - qa browser: description: 'Browser' type: choice options: [chromium, firefox, webkit, all] jobs: test: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - run: npx playwright test --project=${{ inputs.browser }}

How to Trigger

  • UI: Actions tab → Select workflow → "Run workflow"
  • CLI: gh workflow run test.yml -f environment=staging

Caching for Speed & Cost

❌ Without Cache

Job 1: npm install (2 min)

Job 2: npm install (2 min)

Job 3: npm install (2 min)

6 min = $0.60

✅ With Cache

Job 1: npm install (2 min)

Job 2: cache restore (10s)

Job 3: cache restore (10s)

2.5 min = $0.25 (58% savings!)

# Automatic npm caching - uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' # ← Auto-caches node_modules

Bonus: Cache expires after 7 days, 10 GB max per repo

Slack Notifications

- name: Send Slack notification if: always() uses: slackapi/slack-github-action@v1 with: payload: | { "text": "${{ job.status == 'success' && '✅' || '🚨' }} Tests ${{ job.status }}", "blocks": [ { "type": "section", "text": { "type": "mrkdwn", "text": "*Repo:* ${{ github.repository }}\n*Status:* ${{ job.status }}" } } ] } env: SLACK_WEBHOOK_URL: ${{ secrets.SLACK_WEBHOOK_URL }}

Troubleshooting Common Issues

❌ Issue 1: Workflow Not Triggering

Cause: YAML syntax error or wrong branch

Fix: Validate YAML, check branch filter

❌ Issue 2: Tests Pass Locally, Fail in CI

Cause: Missing .env or headless issues

Fix: Create .env from secrets, use --with-deps

❌ Issue 3: Browser Not Found

Cause: Browsers not installed

Fix: npx playwright install --with-deps chromium

Troubleshooting (Continued)

❌ Issue 4: Test Timeout

Cause: CI slower than local machine

Fix: Increase timeout: timeout: 60000

❌ Issue 5: Out of Disk Space

Cause: Test artifacts filling disk (14 GB limit)

Fix: Cleanup or use jlumbroso/free-disk-space action

Debugging: Check Actions tab, enable debug with ACTIONS_STEP_DEBUG=true, use if: always() for artifacts

Security Best Practices

✅ Do This

  • Use GitHub Secrets
  • Pin actions to SHA
  • Minimum permissions
  • Validate actions
  • Branch protection

❌ Don't Do This

  • Hardcode secrets
  • Use @latest
  • Excessive permissions
  • Allow untrusted forks
  • Ignore advisories
# ✅ Good: Pin to SHA - uses: actions/checkout@b4ffde65f46336ab88eb53... permissions: contents: read checks: write

Critical: Enable branch protection → Require status checks

Advanced Workflow Patterns

Pattern 1: Dependent Jobs

jobs: build: runs-on: ubuntu-latest steps: - run: npm run build test: needs: build # Waits for build steps: - run: npm test deploy: needs: [build, test] # Waits for both steps: - run: npm run deploy

Pattern 2: Conditional Jobs

deploy-staging: if: github.ref == 'refs/heads/develop' steps: - run: deploy staging deploy-production: if: github.ref == 'refs/heads/main' steps: - run: deploy production
