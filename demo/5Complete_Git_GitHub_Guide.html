Git vs GitHub

Git

  • Version control system
  • Tracks changes locally
  • Creates snapshots (commits)
  • Built into VSCode!

GitHub

  • Cloud storage for code
  • Share with team
  • Backup your work
  • GitHub Classroom!
Git = Tool on your PC | GitHub = Cloud service | VSCode = Your interface

1 Create Repository on GitHub

Steps to Create

  • Go to github.com → Sign in
  • Click New button
  • Enter repository name
  • Add description (optional)
  • Select Public or Private
  • Check "Add a README file"
  • Click Create repository

Naming Tips

  • Use lowercase letters
  • Use hyphens for spaces
  • Be descriptive

Examples:

playwright-tests
automation-framework
cypress-demo

2 Clone Repository to VSCode

Get the Clone URL

  • On GitHub repo page
  • Click green Code button
  • Copy the HTTPS URL
https://github.com/username/repo-name.git

In VSCode

  • Open VSCode
  • Press Ctrl+Shift+P
  • Type "Git: Clone"
  • Paste the URL
  • Choose folder location
  • Click "Open" when prompted
Now your GitHub repo is connected to VSCode!

Staging Files in VSCode

Changes (3)

Staged Changes (1)
A config.ts ➖

How to Stage

  • Hover over file → Click +
  • Right-click → "Stage Changes"
  • Click + on "Changes" header for all

To Unstage

  • Click − next to staged file
Only staged files will be included in your commit!

SOURCE CONTROL

Shortcut: Ctrl+Enter

Good Commit Messages

  • Be specific and descriptive
  • Start with action verb
  • Keep under 50 characters

Good Examples:

Add login page tests
Fix selector for submit button
Update test configuration
Refactor page object model

Push & Sync to GitHub

After Committing

Your changes are saved locally. Now push to GitHub:

  • Click Sync Changes button
  • Or click 🔄 in the bottom status bar
  • Or use ... menu → Push

Getting Team Changes

To get others' changes:

  • Click 🔄 Sync (pulls + pushes)
  • Or ... menu → Pull

GitHub Classroom Workflow

Accept Assignment
Clone in VSCode
Work & Commit
Sync = Submit!

For Assignments

  • Click assignment link from instructor
  • Accept the assignment
  • Copy your personal repo URL
  • Clone in VSCode (Ctrl+Shift+P → Git: Clone)

To Submit

  • Make your changes
  • Stage files (+)
  • Commit with message
  • Sync/Push to GitHub
  • That's it - submitted!

Best Practices

Do This

  • Commit often (small chunks)
  • Write clear commit messages
  • Sync before starting work
  • Review changes before committing

Avoid

  • One huge commit at the end
  • "Fixed stuff" as message
  • Forgetting to sync/push
  • Committing node_modules
Commit small, commit often, sync regularly!
