App Overview & Architecture

HRMS is a comprehensive Human Resource Management System with 7 major modules covering the complete employee lifecycle. The app simulates real network behavior with loading states and delays, perfect for practicing automation waits.

Module Navigation Key Functionality
Dashboard Default tab on load Stats, quick actions, activity feed
People (PIM) Sidebar → People Employee directory, CRUD operations
Leave Management Sidebar → Leave Apply leave, approve/reject workflow
Time & Attendance Sidebar → Time Clock in/out, attendance tracking
Recruitment Sidebar → Recruitment Job postings, candidate pipeline
Performance Sidebar → Performance Goals, OKRs, reviews
Administration Sidebar → Administration Users, audit logs, reports
Important for automation: The app uses simulated delays (800-1200ms). Always wait for elements to be visible and ready before interacting with them.

1. Dashboard

The dashboard provides an overview of key HR metrics and quick access to common actions.

  • 1Observe the stats cards at the top showing Total Employees, On Leave Today, Pending Requests, Open Positions, and Pending Reviews
  • 2Find the Quick Actions section with buttons for common tasks like Add Employee, Approve Leaves, Post Job, and View Reports
  • 3Locate the Recent Activity feed showing the latest HR activities with timestamps
  • 4Click any quick action button to navigate to the respective module and open the relevant form
  • 5Verify that stats update automatically when data changes in other modules

2. People Management (PIM)

The People Information Module manages the employee directory with full CRUD operations.

  • 1Locate the People (PIM) link in the sidebar navigation and click to view the employee directory
  • 2Find the search input field and type to filter employees by name, ID, or email — the table updates in real-time
  • 3Locate the department filter dropdown and select a department to filter the employee list
  • 4Find the Add Employee button in the toolbar and click to open the employee form modal
  • 5In the modal, locate the Personal Information section with fields for First Name, Last Name, Email, Phone, DOB, and Gender
  • 6Find the Employment Details section with Job Title dropdown, Department dropdown, Join Date, and Status fields
  • 7Click Save Employee button and wait for the success notification
  • 8In the employee table, locate the action buttons (View, Edit, Delete) for each row
  • 9Click the View button to open the employee profile modal with detailed information
  • 10Click the Edit button to modify employee details in the form modal

3. Leave Management

Manage leave requests, check balances, and process approvals.

  • 1Locate the Leave Management link in the sidebar and click to navigate
  • 2Observe the leave balance cards at the top showing Annual, Sick, Personal, and Comp-Off balances
  • 3Find the Apply Leave button and click to open the leave request modal
  • 4In the modal, locate the Leave Type dropdown and select the type of leave
  • 5Find the Start Date and End Date pickers and select your leave period
  • 6Observe that the Number of Days field auto-calculates based on the selected dates
  • 7Locate the Reason textarea and enter a reason for the leave request
  • 8Click Submit Request and wait for the success notification
  • 9In the leave requests table, find requests with Pending status
  • 10Locate the Approve and Reject buttons for pending requests to process approvals

4. Time & Attendance

Track work hours with clock in/out functionality and view attendance records.

  • 1Locate the Time & Attendance link in the sidebar and click to navigate
  • 2Observe the clock widget showing the current date, time, and clock status
  • 3Find the Hours Today display showing accumulated work hours
  • 4Locate the Clock In button and click to start your work session
  • 5Observe that the status changes to "Clocked In" with the clock-in time displayed
  • 6Notice the button changes to Clock Out after clocking in
  • 7Watch the Hours Today counter update in real-time as time passes
  • 8Click Clock Out to end your work session
  • 9View the attendance table below showing today's attendance records
  • 10Observe the total hours and status for each employee record

5. Recruitment (ATS)

Manage job postings and track candidates through the hiring pipeline.

  • 1Locate the Recruitment link in the sidebar and click to navigate
  • 2Observe the candidate pipeline at the top showing counts for Applied, Screening, Interview, Offer, and Hired stages
  • 3Find the Post New Job button and click to open the job posting modal
  • 4In the modal, fill in the Job Title, Department, Location, Employment Type, Experience, Salary Range, and Description
  • 5Click Post Job button and wait for the success notification
  • 6View the job cards in the grid showing title, department, location, type, and applicant count
  • 7Locate the View button on a job card and click to see candidates for that position
  • 8In the candidates modal, observe the candidate details including name, experience, skills, and rating
  • 9Find the stage dropdown for each candidate to move them through the pipeline
  • 10Change a candidate's stage and observe the pipeline counts update

6. Performance Management

Track goals, OKRs, and conduct performance reviews.

  • 1Locate the Performance link in the sidebar and click to navigate
  • 2Find the Add Goal button and click to open the goal creation modal
  • 3Fill in the Goal Title, Description, Due Date, and Priority fields
  • 4Click Save Goal and verify the goal appears in the goals list
  • 5Observe the goal cards showing title, progress bar, due date, and priority badge
  • 6Notice the progress bar color changes based on completion percentage
  • 7Scroll down to find the Performance Reviews table
  • 8Locate a pending review and click the Complete button to open the review modal
  • 9In the review modal, find the star rating selector and enter Strengths and Areas for Improvement
  • 10Click Submit Review and verify the review status changes to Completed

7. Administration

Manage users, roles, and view audit logs for compliance.

  • 1Locate the Administration link in the sidebar and click to navigate
  • 2Find the User Management table showing username, email, role, status, and last login
  • 3Observe the role badges indicating HR Manager, Manager, or Employee roles
  • 4Locate the action buttons (Edit, Reset Password) for each user
  • 5View the Audit Logs panel on the right showing recent system activities
  • 6Observe the log entries with timestamp, user, action type, module, and details
  • 7Note the action badges colored by type: CREATE (green), UPDATE (gray), DELETE (red), APPROVE (blue)

Test Scenarios

Happy Path

TC-001: Add New Employee

Navigate to PIM → Click Add Employee → Fill form → Save → Verify in table

TC-002: Edit Employee Details

Find employee in table → Click Edit → Modify fields → Save → Verify changes

TC-003: Apply for Leave

Navigate to Leave → Click Apply → Fill dates and reason → Submit → Verify in table

TC-004: Approve Leave Request

Find pending request → Click Approve → Verify status changes to Approved

TC-005: Clock In and Out

Navigate to Time → Click Clock In → Verify status → Clock Out → Check hours

TC-006: Post New Job

Navigate to Recruitment → Post Job → Fill details → Submit → Verify in grid

TC-007: Move Candidate Stage

View job candidates → Change stage dropdown → Verify pipeline count updates

TC-008: Create and Track Goal

Add goal → Set title and due date → Verify in goals list with progress

TC-009: Complete Performance Review

Find pending review → Click Complete → Enter rating and feedback → Submit

TC-010: Search and Filter Employees

Type in search → Verify table filters → Select department → Verify filter works

Negative / Edge Cases

TC-011: Empty Employee Form

Click Save without filling required fields → Verify validation error appears

TC-012: Invalid Date Range Leave

Set end date before start date → Verify days show 0 or negative → Cannot submit

TC-013: Delete Employee

Click delete button → Confirm in dialog → Verify employee removed from table

TC-014: Reject Leave Request

Find pending request → Click Reject → Verify status changes to Rejected

TC-015: Empty Goal Title

Try to save goal without title → Verify validation message appears

TC-016: Empty Review Feedback

Try to submit review without strengths → Verify validation prevents submission

TC-017: Search No Results

Search for non-existent employee → Verify empty state message appears

TC-018: Quick Actions Navigation

Click each quick action → Verify correct tab opens with modal/form ready

TC-019: Modal Close Behavior

Open modal → Click X → Verify modal closes → Click outside → Verify closes

TC-020: Data Persistence

Add data → Refresh page → Verify all data persists in localStorage
