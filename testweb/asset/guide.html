App Overview & Architecture

AssetExplorer is a full-featured IT Asset Management application simulating ManageEngine's AssetExplorer. It covers the complete asset lifecycle — from procurement to disposal — across 8 functional modules. Data is stored locally and simulates real network delays for realistic testing.

Module Navigation Key Functionality
Dashboard Default tab on load Stats overview, quick actions, recent assets, low stock alerts
IT Assets Sidebar → IT Assets CRUD operations, search, filter, view/edit/delete modals
Non-IT Assets Sidebar → Non-IT Assets Furniture, AV equipment register with delete
Software Sidebar → Software License compliance, metering, usage tracking
CMDB Sidebar → CMDB CI relationship map — Network → Server → Endpoint → Software
Purchase Orders Sidebar → Purchase Orders PO approval/rejection workflow
Contracts Sidebar → Contracts Vendor contracts with expiry tracking
Consumables Sidebar → Consumables Stock levels, min stock alerts
Important for automation: The app uses simulated async delays (800ms–1.2s). Always wait for elements to be visible after triggering actions. Data resets on each page load.
Default data: Contains 12 hardware assets, 5 non-IT assets, 10 software licenses, 6 purchase orders, 6 contracts, and 6 consumables.

1. Dashboard

The dashboard provides a unified overview with 8 stat cards, 6 quick action buttons, a recent assets table, and low stock alerts.

  • 1On page load, the Dashboard tab is displayed as the default active view
  • 2Locate the 8 stat cards showing counts for: IT Assets, Non-IT Assets, Software Licenses, Pending POs, Contracts, Consumables, Compliance percentage, and Expiring contracts
  • 3Click on any stat card to navigate to the corresponding module tab
  • 4Find the Quick Actions section with 6 buttons: Register Asset, License Compliance, New PO, View CMDB, Manage Contracts, Check Stock
  • 5Scroll down to view the Recent Assets table showing the 6 most recently purchased IT assets
  • 6Check the Low Stock Alerts section displaying consumables below their minimum stock level
Practice tip: Identify and interact with the stat cards. Verify that clicking each card navigates to the correct module tab.

2. IT Assets (CRUD)

The IT Assets tab provides complete CRUD (Create, Read, Update, Delete) operations for hardware assets. This is the primary module for practicing form interactions, modal workflows, and table manipulation.

Asset Types in Dataset:

Workstation, Laptop, Server, Monitor, Printer, Network Switch — 12 items total with statuses: In Use, In Stock, Maintenance, Retired

Viewing Assets:
  • 1Click on "IT Assets" in the left sidebar navigation menu
  • 2Wait for the assets table to load (there's a brief loading delay)
  • 3Observe each row displaying: Asset Tag, Hostname, Type, Model, Assigned User, Location, Status badge, and Action buttons
  • 4Find the asset count label above the table showing the total number of IT assets
Search & Filter:
  • 1Locate the search input field and type a keyword — the table filters in real-time as you type
  • 2Find the status filter dropdown and select from: All, In Use, In Stock, Maintenance, or Retired to filter assets by status
View Asset (Read):
  • 1Locate the view button (eye icon) in the Actions column of any row and click it
  • 2A modal dialog opens displaying the complete asset details in read-only format
  • 3Review all 17 fields: Tag, Hostname, Type, Model, Serial, IP, OS, CPU, RAM, Storage, User, Department, Location, Status, Purchase Date, Warranty End, Cost
  • 4Close the modal by clicking the X button or the "Close" button in the footer
Edit Asset (Update):
  • 1Locate the edit button (pencil icon) in the Actions column of any row and click it
  • 2An edit modal opens with all fields pre-populated with the current asset values
  • 3Modify any of the editable fields: Tag, Hostname, Type, Model, Serial, IP Address, Assigned User, Department, Location, or Status
  • 4Click the "Save Changes" button to submit — a success notification appears and the table refreshes with updated data
Register Asset (Create):
  • 1Click the "New Asset" button in the toolbar, or use the Quick Action "Register IT Asset" from Dashboard
  • 2A registration modal opens with an empty form
  • 3Fill in the required fields (marked with *): Asset Tag, Hostname, and Model
  • 4Optionally fill in: Type (dropdown), Serial Number, IP Address, Assign To, Department (dropdown), and Location
  • 5Click the "Register Asset" button — a loading spinner appears briefly, then a success notification shows
  • 6The new asset appears in the IT Assets table with status "In Stock"
Delete Asset (Decommission):
  • 1Locate the delete button (trash icon) in the Actions column of any row and click it
  • 2A browser confirmation dialog appears asking to confirm the decommission action
  • 3Click "OK" to confirm — the asset is removed, a warning notification shows, and the table refreshes
  • 4Click "Cancel" to abort — no changes are made

3. Non-IT Assets

Non-IT assets are items without an IP address: furniture, AV equipment, appliances, office equipment. 5 items in the default dataset.

  • 1Click on "Non-IT Assets" in the left sidebar navigation menu
  • 2Wait for the non-IT assets table to load
  • 3Review the columns: Asset Tag, Name, Type, Location, Assigned To, Status, and Actions (delete only)
  • 4Asset types include: Furniture, AV Equipment, Office Equipment, and Appliance
  • 5Delete functionality works the same as IT assets — click trash icon and confirm in the dialog

4. Software Asset Management

Tracks 10 software licenses with three key metrics: compliance status, usage metering, and cost analysis.

License Compliance:
  • 1Click on "Software" in the left sidebar navigation menu
  • 2Wait for the software licenses table to load
  • 3Look for Compliant badges (green) — these indicate licenses where installed count is within purchased limit
  • 4Identify Over-Licensed badges (red) — these show more installations than purchased licenses (e.g., Adobe CC: 24 installed but only 20 purchased)
  • 5Find Under-Utilized badges (yellow) — these indicate low usage ratio compared to available licenses (e.g., Zoom: only 42 of 100 licenses used)
Software Metering:
  • 1Look for Frequent usage badges — indicates actively and regularly used licenses
  • 2Find Occasional usage badges — software used sometimes but not regularly
  • 3Identify Rarely usage badges — these are candidates for license reclamation
Compliance Bar Visual:

Each software row has a visual compliance bar showing the percentage of licenses used. Green bars indicate healthy compliance, yellow bars show warning levels, and red bars indicate over-licensing issues.

5. Configuration Management Database (CMDB)

The CMDB provides a visual CI (Configuration Item) relationship map with 4 layers. Each node is clickable to view the full asset details.

  • 1Click on "CMDB" in the left sidebar navigation menu
  • 2Wait for the visual map to render showing a hierarchical structure
  • 3Observe the Infrastructure Layer at the top — Network Switches represented with blue icons
  • 4Below that, find the Server Layer — Production and Development servers shown with purple icons
  • 5Next is the Endpoint Layer — Laptops and Workstations displayed with green icons (shows first 5 plus a count for remaining)
  • 6At the bottom, see the Software Layer — Top 4 software titles shown with yellow icons
  • 7Notice the vertical connector lines between layers showing the relationships
  • 8Click on any IT asset node to open the View Asset modal with complete details
Note: The CMDB map is dynamically generated from live hardware and software data. Adding or removing assets will automatically update the CMDB view.

6. Purchase Management

Manage purchase orders with approval workflows. 6 POs in default dataset with 3 statuses: approved, pending, rejected.

  • 1Click on "Purchase Orders" in the left sidebar navigation menu
  • 2Wait for the purchase orders table to load
  • 3Review the columns: PO Number, Description with line items, Vendor, Amount, Requested By, Status, and Actions
  • 4Find rows with Pending status — these display both "Approve" and "Reject" buttons in the Actions column
  • 5Click the green Approve button on a pending PO — the status updates to "approved", the approval date is recorded, and a success notification appears
  • 6Click the red Reject button on a pending PO — a confirmation dialog appears, then the status updates to "rejected"
  • 7Note that already approved or rejected POs display the action date instead of buttons
Test Tip: After approving a PO, navigate back to the Dashboard and verify that the "Pending POs" stat card count has decreased by 1.

7. Contract Management

Vendor contract tracking with expiry alerts. 6 contracts covering Software, Cloud, Maintenance, Service, Security, and Facility types.

  • 1Click on "Contracts" in the left sidebar navigation menu
  • 2Wait for the contracts table to load
  • 3Review the columns: Contract ID, Title with notes, Vendor name, Type, Contract Value, Validity Period (start to end dates), and Status
  • 4Identify Active contracts (green badge) — these are within their validity period
  • 5Find Expiring Soon contracts (yellow badge) — these are within the renewal alert window and need attention
  • 6Look for Expired contracts (red badge) — these are past their end date and require renewal
Automation note: The Dashboard's "Expiring Contracts" stat card counts both contracts with "Expiring Soon" and "Expired" statuses combined.

8. Consumables

Bulk-managed single-use items with stock level tracking. 6 items with minimum stock thresholds.

  • 1Click on "Consumables" in the left sidebar navigation menu
  • 2Wait for the consumables table to load
  • 3Review the columns: Item ID, Name, Category, Current Stock (with warning icon if low), Minimum Stock threshold, and Unit Cost
  • 4Identify items below minimum stock — these are highlighted in red bold text with a warning triangle icon
  • 5Note that low stock items also appear on the Dashboard's "Low Stock Alerts" section
Default low stock items: USB-C Adapter Hub (8 in stock, minimum 15) and Keyboard Replacement (5 in stock, minimum 10)

Test Scenarios

Happy Path Scenarios

TC-001: Dashboard Stats Verification

Load the page and verify all 8 stat cards display correct counts matching the stored data

TC-002: Register New IT Asset (Create)

Open the register modal, fill in asset tag, hostname, and model, submit the form, and verify the success notification appears along with the new row in the table

TC-003: View Asset Details (Read)

Click the view button on any asset and verify the modal displays all 17 fields correctly

TC-004: Edit Asset (Update)

Click edit on an asset, change the assigned user name, save changes, and verify the table shows the updated value

TC-005: Decommission Asset (Delete)

Click the delete button, accept the confirmation dialog, and verify the row is removed with a notification shown

TC-006: Search IT Assets

Type "MacBook" in the search field and verify only matching rows remain visible

TC-007: Filter by Status

Select "Retired" from the status dropdown and verify only retired assets are shown

TC-008: Software Compliance Check

Navigate to Software and verify Adobe Creative Cloud shows "Over-Licensed" status with a red compliance bar

TC-009: Approve Purchase Order

Navigate to Purchase Orders, click Approve on a pending PO, and verify the status changes with a success notification

TC-010: CMDB Navigation

Open the CMDB, click on a server node, and verify the View Asset modal opens with the correct server data

TC-011: Low Stock Alert

On the Dashboard, verify the low stock alerts table shows USB-C Adapter Hub (8 current vs 15 minimum)

TC-012: Contract Expiry Tracking

Navigate to Contracts and verify the AWS contract displays an "Expiring Soon" badge

Negative / Edge Cases

TC-013: Register Without Required Fields

Open the register modal, leave tag and hostname empty, click submit, and verify an error notification is shown

TC-014: Cancel Delete Confirmation

Click the delete button on an asset, dismiss the confirmation dialog, and verify the asset still exists in the table

TC-015: Reject Purchase Order

Click reject on a pending PO, accept the confirmation, and verify the status changes to "rejected"

TC-016: Search No Results

Type "ZZZZ" in the IT Assets search field and verify all table rows are hidden (no matching results)

TC-017: Modal Close Without Saving

Open the edit modal, change field values, close without saving, and verify the original data remains unchanged

Cross-Module Scenarios

TC-018: Dashboard → IT Assets Navigation

Click the IT Assets stat card on Dashboard and verify the tab switches to IT Assets with data loaded

TC-019: Quick Action → Register → Dashboard

Use Dashboard Quick Action to register a new asset, then verify the Dashboard stats are updated accordingly

TC-020: PO Approve → Dashboard Sync

Approve a PO, navigate back to Dashboard, and verify the pending PO count has decreased

TC-021: Delete Asset → CMDB Update

Delete a server from IT Assets, navigate to CMDB, and verify the server is removed from the relationship map

TC-022: Full Sidebar Navigation Cycle

Click through all 8 sidebar navigation links and verify each tab loads with the correct content
