User Guide

🏘 LoanEdge – Loan Management System

Complete reference guide for bank officers: manage borrowers, process loan applications, perform credit assessments, track documents, disburse funds, and monitor repayments — all from one dashboard.

🚀 Launch App 💻 Command Center

LoanEdge is a bank officer management system for practicing end-to-end loan lifecycle management. It is designed for QA learners to test real-world banking workflows — from registering a borrower to closing a disbursed loan.

All data is stored in your browser's localStorage via the shared MockAPI layer. No network calls are made. Seed data is pre-loaded on first launch.

Who uses this system?

  • Loan Officers — process applications, conduct credit reviews, update statuses
  • Operations Staff — manage document checklists and disbursement records
  • Collections Team — monitor EMI schedules and flag overdue payments
  • Support Staff — handle borrower queries via the ticketing module
ℹ This is a demo QA practice application. Reload the page to restore seed data. Clear localStorage to start fresh.

The dashboard loads automatically when you open LoanEdge. It gives a real-time snapshot of all operational data.

Stat Cards (8 KPIs)

  • Total Applications — all applications across all statuses
  • Active Borrowers — borrowers with Active status
  • Total Portfolio — sum of all disbursed amounts (₹)
  • Pending Review — applications in Under Review or Submitted
  • Approved — applications with Approved status
  • Overdue EMIs — repayment records with Overdue status
  • Disbursed Loans — active disbursed applications
  • Active Products — loan product types with status Active

How to add a borrower

  1. 1Click the Borrowers tab in the sidebar
  2. 2Click + Add Borrower in the toolbar
  3. 3Fill in all required fields (Name, PAN, Email)
  4. 4Click Save Borrower
✓ Credit Score and Annual Income are used in the EMI pre-fill when creating an application.

Applications are the central entity in LoanEdge. Each application links a borrower to a loan product and carries full lifecycle data: status, officer, amount, and timeline.

Creating a new application

  1. 1Ensure the borrower exists in the Borrowers module
  2. 2Click + New Application
  3. 3Select Borrower, Loan Product, Amount, Tenure, Purpose
  4. 4Assign a Loan Officer ID and save

Filtering applications

Use the status dropdown in the toolbar to filter applications by lifecycle stage. Use the search box to find by App ID or borrower name.

ℹ App IDs are auto-generated in the format LN-2025-XXXX.

Credit Review (underwriting) validates the borrower's creditworthiness before approval. Each assessment is linked to an application.

Key Metrics

  • Credit Score (CIBIL) — 300–900; ≥ 700 typically required for approval
  • DTI (Debt-to-Income) Ratio — monthly obligations ÷ monthly income; ≤ 40% is healthy
  • Existing Loans — number of live loans with other lenders
  • Monthly Income vs Obligation — net income after existing EMIs

Risk Levels

  • Low — credit score > 750, DTI < 30%
  • Medium — credit score 650–750, DTI 30–40%
  • High — credit score < 650, DTI > 40%

Decision options

Pending | Approved | Rejected

✓ Always attach a Credit Assessment before advancing an application to the Approved status.

Each loan application requires a set of supporting documents. This module tracks collection and verification of each document.

Document Types

  • Salary Slip, Bank Statement, IT Return — income verification
  • Property Papers, Auto Invoice, Sale Agreement — asset documents
  • Admission Letter — education loans
  • Address Proof, Photo ID — KYC documents

Document Statuses

  • Missing — document not yet received
  • Received — document received but not yet verified
  • Verified — document authenticated and accepted
⚠ Documents tab badge turns red when any documents are still Missing. Applications in Docs Required status should be cleared here first.

Once an application is approved, the funds must be disbursed to the borrower's bank account. This module records the transfer details.

Fields

  • Application — must be in Approved or Disbursed status
  • Amount & EMI — disbursed principal and calculated monthly EMI
  • Account No / IFSC — beneficiary bank details
  • Transfer Mode — NEFT / RTGS / IMPS / Cheque
  • Reference No — transaction/UTR reference number
  • Status — Pending / Disbursed
✓ After recording a disbursement, update the application status to Disbursed in the Applications module.

The Repayments module maintains the EMI schedule for each disbursed loan, tracking principal and interest breakdowns per installment.

EMI Schedule Fields

  • EMI # — installment number in the loan schedule
  • EMI Amount — total payment = principal + interest
  • Principal / Interest — amortization breakdown
  • Outstanding Balance — remaining loan balance after this payment
  • Due Date / Paid Date — schedule vs actual payment date

Payment Statuses

  • Upcoming — future EMI not yet due
  • Due — EMI due today or soon
  • Paid — EMI paid on time
  • Overdue — past due date, not paid
⚠ Overdue records are counted in the Dashboard KPI and appear in the red sidebar badge count.

Borrowers or officers can raise support tickets linked to specific loan applications. Tickets track resolution progress.

Priority Levels

  • Low — general informational queries
  • Medium — moderate impact, standard SLA
  • High — requires urgent resolution
  • Critical — systemic issue or legal escalation

Ticket Statuses

  • Open — newly raised, unassigned
  • In Progress — being investigated
  • Resolved — issue closed

Application Lifecycle

Scenario 1 – Full loan lifecycle (happy path)

  1. 1Add a new Borrower with credit score 780 and income ₹12L
  2. 2Create an Application for Personal Loan ₹5L, 36 months
  3. 3Add all required Documents and mark them Verified
  4. 4Create a Credit Assessment with Low risk and Approved decision
  5. 5Update Application status to Approved
  6. 6Record a Disbursement via NEFT
  7. 7Add 3 Repayment records (Paid, Paid, Due)
  8. 8Verify Dashboard stats updated correctly

Scenario 2 – Rejection flow

  1. 1Create a borrower with credit score 540
  2. 2Create an application for Business Loan ₹25L
  3. 3Create Credit Assessment: DTI 52%, risk High, decision Rejected
  4. 4Update application status to Rejected
  5. 5Raise a Support Ticket with priority High and subject "Rejection Dispute"

Scenario 3 – Document bottleneck

  1. 1Set application status to Docs Required
  2. 2In Documents, add Salary Slip (Missing), Bank Statement (Missing), PAN Card (Received)
  3. 3Observe the red badge on Documents nav item
  4. 4Update all documents to Verified, observe badge clears
  5. 5Advance application to Under Review

Scenario 4 – Overdue EMI monitoring

  1. 1Open an existing disbursed application
  2. 2Add a Repayment record with status Overdue and a past due date
  3. 3Verify the Overdue EMIs KPI on the dashboard increments
  4. 4Raise a Critical Support Ticket for the borrower
✓ Use the search boxes in each tab to filter records and practice search/filter test cases as well.
